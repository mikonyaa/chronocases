# V1 limits

- Exactly three contracts, ISO Gregorian dates 1900–2100, daily recurrence only. No cron/RRULE, monthly/business calendars, leap seconds, alternative calendars, database/browser/Python product adapters, or arbitrary repository analysis.
- Instants require seconds and `Z` or `±HH:mm`; fractions allow 1..9 digits. Both the written year and resolved UTC year must fit v1, and day-bucket's resolved local date must also fit. Named runtime IANA aliases are supported; numeric timeZone strings are rejected.
- Recurrence's entire nominal-date window must fit the documented transition model: 22..26-hour days, at most one transition inside a day, jumps up to two hours, increasing projected instants across nominal dates. Skipped/repeated civil dates are declined before any occurrence is evaluated. These zones still work for date labels/buckets.
- Expected invalid-input rejection and no-occurrence can PASS. A matching unsupported-transition rejection remains UNSUPPORTED; no occurrence coverage is claimed. The complete correct corpus exits 3 for this reason.
- Node's full ICU and an appropriate historical timezone database are required. Canaries check the offsets needed by each case. They do not certify every offset in a runtime or guarantee the tested application's own timezone database matches Node's. Report the application's separate database in your own integration notes.
- Full CLI isolation is a process boundary for trusted local modules, not a permission sandbox. It does not control grandchildren intentionally created by adapters. The runner never terminates unrelated processes or changes global TZ.
- Limits: fixture 256 KiB, report 5 MiB, at most 1000 cases in a report, JSON depth 20, strings 64 KiB, JSON keys 200 characters and containers 5000 entries. Outcome 32 KiB, combined logs 64 KiB per case, timeout default 3 s (50..60000 ms configurable), child V8 old-space limit 128 MiB. A timeout is distinct from exhausting a recurrence window.
- The explorer renders literal data as text, validates schema/counts, and works as a file. Clipboard permission depends on browser context; selection/manual-copy fallback remains available. It does not execute arbitrary JavaScript or product adapters, upload reports, fetch dependencies or use telemetry.
- Local browser QA uses Chrome in a fresh context, CI uses Chromium. Physical Safari, every browser, all IANA zones and external applications have not been established by these tests.
- Reports preserve inputs and adapter logs and may contain private data. The shipped public demo uses only this project's own date fixtures and functions.
